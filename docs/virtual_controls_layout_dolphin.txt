================================================================================
                    MAPEAMENTO DE CONTROLES VIRTUAIS
================================================================================

Controle Virtual → SDL Gamepad → PAD (GameCube)
─────────────────────────────────────────────────────────────────────────────

Control Stick:
   X+ (Direita)    → SDL_GAMEPAD_AXIS_LEFTX  → PAD_AXIS_LEFT_X_POS
   X- (Esquerda)   → SDL_GAMEPAD_AXIS_LEFTX  → PAD_AXIS_LEFT_X_NEG
   Y+ (Cima)       → SDL_GAMEPAD_AXIS_LEFTY  → PAD_AXIS_LEFT_Y_POS
   Y- (Baixo)      → SDL_GAMEPAD_AXIS_LEFTY  → PAD_AXIS_LEFT_Y_NEG

C-Stick:
   X+ (Direita)    → SDL_GAMEPAD_AXIS_RIGHTX → PAD_AXIS_RIGHT_X_POS
   X- (Esquerda)   → SDL_GAMEPAD_AXIS_RIGHTX → PAD_AXIS_RIGHT_X_NEG
   Y+ (Cima)       → SDL_GAMEPAD_AXIS_RIGHTY → PAD_AXIS_RIGHT_Y_POS
   Y- (Baixo)      → SDL_GAMEPAD_AXIS_RIGHTY → PAD_AXIS_RIGHT_Y_NEG

Botões de Acao:
   A               → SDL_GAMEPAD_BUTTON_SOUTH    → PAD_BUTTON_A
   B               → SDL_GAMEPAD_BUTTON_EAST     → PAD_BUTTON_B
   X               → SDL_GAMEPAD_BUTTON_WEST     → PAD_BUTTON_X
   Y               → SDL_GAMEPAD_BUTTON_NORTH    → PAD_BUTTON_Y

Ombros:
   L               → SDL_GAMEPAD_BUTTON_LEFT_SHOULDER  → PAD_TRIGGER_L
   R               → SDL_GAMEPAD_BUTTON_RIGHT_SHOULDER → PAD_TRIGGER_R
   Z               → SDL_GAMEPAD_AXIS_LEFT_TRIGGER     → PAD_TRIGGER_Z

D-Pad:
   ↑               → SDL_GAMEPAD_BUTTON_DPAD_UP     → PAD_BUTTON_UP
   ↓               → SDL_GAMEPAD_BUTTON_DPAD_DOWN   → PAD_BUTTON_DOWN
   ←               → SDL_GAMEPAD_BUTTON_DPAD_LEFT   → PAD_BUTTON_LEFT
   →               → SDL_GAMEPAD_BUTTON_DPAD_RIGHT  → PAD_BUTTON_RIGHT

Sistema:
   START           → SDL_GAMEPAD_BUTTON_START       → PAD_BUTTON_START

================================================================================
                    COMPORTAMENTO DOS ANALOGICOS
================================================================================

Control Stick (Esquerdo):
─────────────────────────────────────────────────────────────────────────────
- Usado para movimento do personagem
- TOQUE: O stick aparece sob o dedo
- ARRASTAR: Move o personagem na direcao do arrasto
- DEADZONE: 10% (movimentos muito pequenos sao ignorados)


C-Stick (Direito):
─────────────────────────────────────────────────────────────────────────────
- Usado para camera e visao
- TOQUE: O stick aparece sob o dedo
- ARRASTAR: Controla a camera na direcao do arrasto
- C-UP: Visao em primeira pessoa
- C-DOWN: Resetar camera
- C-LEFT/RIGHT: Rotacionar camera


================================================================================
                         GESTOS DE TOQUE
================================================================================

1. TOQUE SIMPLES em botao:
   → Pressiona o botao imediatamente
   → Solta quando o dedo sai do botao

2. TOQUE E ARRASTE no Control Stick:
   → Centro do stick aparece sob o dedo
   → Arrastar move o stick dentro da base
   → Direcao determina movimento do personagem
   → Solta: stick volta ao centro

3. TOQUE E ARRASTE no C-Stick:
   → Similar ao Control Stick
   → Controla a camera ao inves do movimento

4. TOQUE em L/R:
   → Trigger analogico
   → Pressao pode variar (dependendo da implementacao)
