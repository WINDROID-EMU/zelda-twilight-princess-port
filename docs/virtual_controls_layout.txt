================================================================================
                              EXEMPLO DE USO
================================================================================

1. O usuário ativa "Virtual Controls" em Settings > Input
2. Ao tocar na tela, os controles virtuais aparecem
3. Toque no botão A → Evento SDL_EVENT_GAMEPAD_BUTTON_DOWN é injetado
4. Toque no joystick esquerdo e arraste → Eventos SDL_EVENT_GAMEPAD_AXIS_MOTION
5. O jogo processa esses eventos como se fossem de um controle físico
